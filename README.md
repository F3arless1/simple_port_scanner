# simple_port_scanner
A simple TCP port scanner written in python

# features
- Scans a costom range of ports
- Uses Python's 'socket' library
- Handles basic error exceptions

# technologies used
- Python 3

## How to Run
1. Clone or download this repository:

   'bash'
   Linux / macOS (bash/zsh)
   python3 Port_Scanner.py
   
   'PowerShell'
   Windows (Powershell / CMD)
   python Port_Scanner.py

## Disclaimer
This project is for educational and ethical testing purposes only. Only scan target systems you own or have explicit authorization to test
